# 🍬 bonbon

Save your favorite YouTube cooking recipes for later.

## Features

- Paste any YouTube or YouTube Shorts link
- Automatically fetches video title, channel, and thumbnail
- Clean, responsive UI
- Powered by Convex for real-time updates

## Tech Stack

- **Frontend**: Next.js 15, React 19, Tailwind CSS
- **Backend**: Convex (real-time database + serverless functions)
- **Deployment**: Vercel

## Getting Started

1. Clone the repo
2. Install dependencies: `npm install`
3. Set up Convex: `npx convex dev`
4. Add your Convex URL to `.env.local`
5. Run: `npm run dev`
